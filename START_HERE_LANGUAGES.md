## 🐛 Troubleshooting

### Problem: Backend not running
```
Error: Backend Error: fetch failed
```
**Fix**: 
```bash
cd backend
node server.js
```

### Problem: Language not working
```
Error: Compiler not found
```
**Fix**: Install the compiler for that language
- Python: https://python.org
- Java: https://oracle.com/java
- C++: Install MinGW or GCC

### Problem: Test fails
```
Error: Network error
```
**Fix**: Make sure backend is running first
