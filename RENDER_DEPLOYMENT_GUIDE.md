# Render.com Deployment Guide

## Quick Deploy to Render.com

### Prerequisites
- GitHub account with your code pushed
- Render.com account (free tier available)
- Gemini API key
- Clerk publishable key (optional, for authentication)

## Step-by-Step Deployment

### 1. Push Code to GitHub
```bash
git add .
git commit -m "Ready for Render deployment"
git push origin main
```

### 2. Connect to Render

1. Go to [Render.com](https://render.com)
2. Sign in with GitHub
3. Click **"New +"** → **"Blueprint"**
4. Connect your GitHub repository
5. Render will automatically detect `render.yaml`

2. Connect your repository

## Post-Deployment

### 1. Verify Backend
Visit: `https://your-backend.onrender.com/health`

Should return:
```json
{
  "status": "OK",
  "version": "2.0.0",
  "database": {
    "status": "disconnected",
    "message": "Running in offline mode"
  }
}
```

### 2. Test AI API
Visit: `https://your-backend.onrender.com/api/ai/health`

Should return:
```json
{
  "status": "healthy",
  "service": "AI Generator API",
  "geminiConfigured": true
}
```

### 3. Verify Frontend
Visit: `https://your-frontend.onrender.com`

Your app should load successfully!

## Troubleshooting

### Backend Won't Start
- Check logs in Render dashboard
- Verify `GEMINI_API_KEY` is set correctly
- Ensure `backend-new` directory path is correct

### Frontend Build Fails
- Check if `npm run build` works locally
- Verify all dependencies are in `package.json`
- Check build logs for specific errors

### AI Not Working
- Verify `GEMINI_API_KEY` is set in backend
- Check backend logs for API errors
- Test API health endpoint

### CORS Errors
- Ensure `FRONTEND_URL` is set correctly in backend
- Check CORS configuration in `backend-new/server.js`

## Free Tier Limitations

Render Free Tier includes:
- ✅ 750 hours/month of runtime
- ✅ Automatic HTTPS
- ✅ Custom domains
- ⚠️ Services spin down after 15 minutes of inactivity
- ⚠️ Cold starts take 30-60 seconds

### Handling Cold Starts

Add this to your frontend to handle cold starts gracefully:

```javascript
// Show loading message for first request
const [isWakingUp, setIsWakingUp] = useState(false);

const callAPI = async () => {
  setIsWakingUp(true);
  try {
    const response = await fetch(API_URL);
    // ... handle response
  } finally {
    setIsWakingUp(false);
  }
};
```

## Updating Your Deployment

### Push Updates
```bash
git add .
git commit -m "Update description"
git push origin main
```

Render will automatically:
1. Detect the push
2. Rebuild your services
3. Deploy the new version

### Manual Redeploy
1. Go to Render dashboard
2. Select your service
3. Click **"Manual Deploy"** → **"Deploy latest commit"**

## Custom Domain (Optional)

1. Go to your service in Render
2. Click **"Settings"** → **"Custom Domain"**
3. Add your domain
4. Update DNS records as instructed
5. Wait for SSL certificate (automatic)
