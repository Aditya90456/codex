## 👥 User Journey & How to Use

### For Students/Learners

#### Step 1: Sign Up & Onboarding
1. Visit the platform and click "Sign Up"
2. Complete profile setup
3. Take skill assessment (optional)
4. Get personalized learning path

#### Step 2: Start Learning
1. **Navigate to Web Playground** (`/web-playground`)
2. Browse assignments by difficulty:
   - 🌱 Beginner (Portfolio, Landing Pages)
   - 🔥 Intermediate (Todo Apps, APIs)
   - ⚡ Advanced (E-commerce, Dashboards)
   - 🚀 Expert (Video Streaming, Real-time Apps)

#### Step 3: Complete Assignments
1. Click "Start Challenge" on any assignment
2. Read requirements and test cases
3. Write HTML, CSS, and JavaScript
4. Submit for automated evaluation
5. Get instant score and feedback
6. Earn points and climb leaderboard

#### Step 4: Build Projects
1. **Navigate to Web Dev Studio** (`/web-studio`)
2. Choose framework (Vanilla JS, React, Vue, Tailwind)
3. Write code in Monaco editor
4. See live preview (Mobile/Tablet/Desktop)
5. Use AI assistance for help
6. Save and export projects

#### Step 5: Track Progress
1. View stats dashboard
2. Check leaderboard ranking
3. Download certificates
4. Share projects on social media

### For Educators/Bootcamps

#### Setup
1. Create organization account
2. Add students via email invites
3. Assign custom assignments
4. Set deadlines and milestones

#### Monitoring
1. View student progress dashboard
2. Track completion rates
3. Review submitted code
4. Provide feedback

#### Reporting
1. Generate progress reports
2. Export analytics
3. Identify struggling students
4. Measure learning outcomes

### For Businesses/HR

#### Employee Training
1. Create company account
2. Enroll employees
3. Assign skill-specific tracks
4. Monitor completion

#### Hiring Assessment
1. Create custom coding challenges
2. Send to candidates
3. Review automated scores
4. Compare candidates
