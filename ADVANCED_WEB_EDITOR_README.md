# 🚀 Advanced Web IDE - Professional Web Development Environment

A comprehensive, feature-rich web development IDE built with React and Monaco Editor, designed for modern web development workflows.

## ✨ Features

### 🎯 Core Development Features
- **Monaco Editor Integration** - Full VS Code editor experience in the browser
- **Multi-Language Support** - HTML, CSS, JavaScript, TypeScript, JSX, TSX
- **Live Preview** - Real-time preview with hot reload
- **Advanced TypeScript Support** - Full type checking and IntelliSense
- **Multiple Layout Modes** - Horizontal, vertical, preview-only, editor-only, grid
- **Responsive Preview** - Test across different device sizes

### 🛠️ Advanced Developer Tools
- **Live Reload** - Automatic preview updates as you type
- **Error Overlay** - Runtime error display with stack traces
- **TypeScript Compiler** - Real-time type checking
- **ESLint Integration** - Code linting and quality checks
- **Code Formatter** - Automatic code formatting (Prettier-style)
- **Advanced Themes** - Multiple professional themes (Dark Pro, Monokai, Dracula, etc.)

### 📁 Project Management
- **File Explorer** - Advanced file management with search
- **Project Templates** - Pre-configured project setups
- **Import/Export** - Save and load complete projects
- **Multiple Files** - Work with multiple files simultaneously
- **File Icons** - Visual file type identification

### 🎨 UI/UX Features
- **Modern Interface** - Clean, professional design
- **Fullscreen Mode** - Distraction-free coding
- **Customizable Layout** - Flexible panel arrangements
- **Keyboard Shortcuts** - Professional IDE shortcuts
- **Responsive Design** - Works on all screen sizes

### 🔧 Advanced Editor Features
- **Multi-Cursor Support** - Edit multiple locations simultaneously
- **Code Folding** - Collapse code sections
- **Bracket Matching** - Visual bracket pair highlighting
- **Line Operations** - Duplicate, move, delete lines
- **Comment Toggle** - Quick comment/uncomment
- **Format Document** - One-click code formatting
- **Mouse Wheel Zoom** - Zoom in/out with mouse wheel

## 🚀 Getting Started

### Prerequisites
- Node.js 16+ 
- React 18+
- Modern web browser

### Installation
The Advanced Web Editor is integrated into the main application. Access it through:

1. Launch the main application
2. Click "Advanced Web IDE" in the navigation
3. Start coding immediately with the default React TypeScript template

## 📖 Usage Guide

### Creating a New Project
1. Select a project template from the dropdown
2. The editor will load with pre-configured files
3. Start editing in the Monaco editor
4. See live preview in the right panel

### Working with Files
- **Add File**: Click the "+" button in the file explorer
- **Delete File**: Hover over a file and click the "×" button
- **Switch Files**: Click on any file in the explorer
- **Search Files**: Use the search box in the file explorer

### Layout Options
- **Horizontal Split**: Editor on left, preview on right
- **Vertical Split**: Editor on top, preview on bottom
- **Preview Only**: Full-screen preview mode
- **Editor Only**: Full-screen editor mode
- **Grid Layout**: Advanced multi-panel layout

### Responsive Testing
- Select device type from the responsive dropdown
- Preview automatically adjusts to selected dimensions
- Test mobile, tablet, and desktop layouts

### Developer Tools
- **Enable Live Reload**: Automatic preview updates
- **TypeScript Checking**: Real-time type validation
- **Linting**: Code quality analysis
- **Error Overlay**: Runtime error display
- **Network Panel**: Monitor network requests (coming soon)
- **Performance Panel**: Performance analysis (coming soon)

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl/Cmd + S` | Save current file |
| `Ctrl/Cmd + Enter` | Run/Preview code |
| `Ctrl/Cmd + Shift + Enter` | Open preview in new tab |
| `Ctrl/Cmd + D` | Duplicate current line |
| `Ctrl/Cmd + Shift + K` | Delete current line |
| `Alt + ↑/↓` | Move line up/down |
| `Ctrl/Cmd + /` | Toggle comment |
| `Ctrl/Cmd + Shift + F` | Format document |

## 🔄 Project Import/Export

### Export Project
- Click the export button (download icon)
- Downloads a JSON file with all project data
- Includes files, settings, and configuration

### Import Project
- Click the import button (upload icon)
- Select a previously exported JSON file
- Project loads with all files and settings restored
