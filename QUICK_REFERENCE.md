# LeetCode Editor - Quick Reference 🚀

## 🎯 Main Features

### 1. Mind Control (Purple Panel)
- **4 Modes**: Approach 🧠 | Solution 💡 | Optimization ⚡ | Stuck 🎯
- **Shortcut**: `Ctrl+Enter` to add thought
- **Auto-save**: Enabled by default
- **Export**: Download thoughts as JSON

### 2. Camera Capture (Dark Panel)
- **6 Emotions**: Focused | Confused | Excited | Neutral | Frustrated | Happy
- **Focus**: 0-100% tracking
- **Auto-mode**: Switches thinking mode based on emotion
- **Privacy**: Local processing only

### 3. Auto-Detection (Blue Panel)
- **Languages**: JS, Python, Java, C++, TypeScript
- **Algorithms**: 12+ patterns detected
- **Complexity**: Time & Space analysis
- **Predictions**: AI suggests next actions
- **Suggestions**: Smart optimization hints

## ⌨️ Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `Ctrl+Enter` | Add thought |
| `Ctrl+S` | Save code |
| `Ctrl+/` | Comment |
| `Esc` | Close overlay |

## 🚀 Quick Start

1. Open `/leetcode`
2. All panels auto-open
3. Start typing code
4. Auto-detection begins
5. (Optional) Activate camera
6. Capture thoughts as you solve

## 💾 Data Storage

- **Thoughts**: localStorage per problem
- **Camera**: No recording, local only
- **Analysis**: Real-time, not stored
- **Export**: JSON download available

## 🔧 Panel Controls

### Mind Control
- Toggle visibility: Eye icon
- Clear all: Trash icon
- Export: Save icon

### Camera
- Start/Stop: Camera button
- Shows: Emotion + Focus
- Auto-switches: Thinking mode

### Auto-Detection
- Always visible when typing
- Updates every 10 keystrokes
- Shows: Algorithm, Complexity, Predictions
