# Codex Logo Assets

This folder contains the official logo assets for the Codex web editor.

## Files

### `codex-logo.svg`
- **Size**: 120x40px
- **Usage**: Main horizontal logo with text
- **Best for**: Headers, navigation bars, landing pages
- **Features**: Gradient background, code brackets, "Codex" text

### `codex-icon.svg`
- **Size**: 32x32px
- **Usage**: Icon-only version
- **Best for**: Favicons, app icons, small UI elements
- **Features**: Square format, gradient background, code brackets

### `logo.png` (legacy)
- **Status**: Legacy file, replaced by SVG versions
- **Recommendation**: Use SVG versions for better scalability

## Design Elements

- **Colors**: Blue to purple gradient (#3B82F6 → #7C3AED → #EC4899)
- **Symbol**: Code brackets `< >` with a center dot
- **Typography**: Inter font family, bold weight
- **Style**: Modern, professional, developer-focused

## Usage Guidelines

1. **Preferred Format**: Always use SVG versions when possible
2. **Scaling**: SVG files scale perfectly at any size
3. **Background**: Logos work best on dark backgrounds
4. **Spacing**: Maintain adequate whitespace around the logo
5. **Modifications**: Do not modify colors or proportions

## Implementation

The logos are automatically used in:
- Browser favicon (`codex-icon.svg`)
- Navigation bar (`codex-logo.svg`)
- Loading screen (`codex-icon.svg`)
- Main editor header (`codex-icon.svg`)
